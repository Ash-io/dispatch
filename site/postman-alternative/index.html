Dispatch / Postman alternative

A lightweight, native alternative to Postman

Dispatch is a native API client for REST, WebSocket, gRPC and GraphQL. It opens your Postman collections, runs their scripts, and can sync both ways with your Postman workspaces, so you can switch on your own while your team stays where it is.

Download Dispatch for macOS, Windows or Linux. No account needed.

What carries over from Postman

  • Postman collections (v2.0 and v2.1) and environments, plus OpenAPI 3, Swagger 2, Insomnia (v4 and v5) and HAR imports. Export writes standard Postman files.
  • Variables resolve in Postman's order: local, data, environment, collection, then globals, with shared and current values kept apart the same way. Dynamic variables such as {{$guid}} work.
  • Pre-request and post-response scripts with the pm API, collection and folder scripts, and pm.execution.setNextRequest in the runner.
  • Auth: Bearer, Basic, API key, OAuth 2.0 (client credentials, password, authorization code with PKCE), AWS Signature v4, Digest and Hawk.
  • Examples, docs written in Markdown, and folders, all syncing both ways when you connect a Postman account.

What Dispatch adds

  • Requests sent from Rust, so there are no browser CORS limits, with a DNS, TCP and TLS, first byte and download timing breakdown.
  • Load testing with up to 500 virtual users, local mock servers from saved examples, and side-by-side comparison of a request across two environments.
  • Collections saved as readable files for Git, and a command-line runner for CI with junit and json reports.
  • A Vault for secrets, referenced as {{vault:name}}, that never syncs or exports and can't be read by scripts.
  • An optional self-hosted team server with its own users, roles, per-workspace access and an audit log, on your own machine, Docker or Cloudflare.

Limits to know about

  • gRPC requests are saved with your open tabs. They aren't part of Postman collections, so they don't sync.
  • Auth types Dispatch can't apply yet are left untouched, so they survive a round trip, but those requests won't authenticate in Dispatch.
  • Dispatch has no hosted cloud of its own. Teams share work through Postman sync or a Dispatch server they run.

Questions

Can I use Dispatch without a Postman account?

Yes. The built-in local profile keeps requests, collections and environments on your device, with no account. Postman sync is optional.

Will my Postman collections and scripts work?

Dispatch imports Postman collections (v2.0 and v2.1) and environments, resolves variables in the same order as Postman, and runs pre-request and post-response scripts with the pm API, including pm.test, pm.expect, pm.sendRequest and the bundled chai, crypto-js and lodash libraries.

Can my team keep using Postman while I use Dispatch?

Yes. Add your Postman account as a profile and Dispatch reads and writes your workspaces, collections, environments and globals through Postman's official API. If a collection changed in Postman since your last sync, Dispatch asks before overwriting.

Can a team stop using Postman completely?

Yes. The self-hosted Dispatch server has its own users and roles, can store workspaces in its own database, and can copy existing Postman workspaces onto it in one step.

Which platforms does Dispatch run on?

macOS 13 and later (Apple Silicon and Intel), Windows 10 and 11, and Linux (x86_64, glibc).

How much does Dispatch cost?

Dispatch is free to download from GitHub, and its source code is public there.

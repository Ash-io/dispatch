Install Dispatch and send your first request

Download the app, skip the sign-up, and get a real response back in under a minute.

Hello! Let's get you started with Dispatch. In this guide, we'll install it, then send our very first request. No account needed.

  1. Download Dispatch

    Go to dispatch.ashlabs.xyz and click Download, or run the one-line installer.

    First, go to dispatch.ashlabs.xyz. Click Download for your system, or copy the one-line installer into your terminal.

  2. Start without an account

    Choose Start on this device. Everything stays on your computer.

    Open Dispatch. You can connect Postman later, but for now, click Start on this device. Your work stays right here on your computer.

  3. Open a new request

    Click New request, or press ⌘+T.

    Now click New request. You can also press ⌘ T, or Control T on Windows.

  4. Enter the URL

    Paste or type the address. Query params fill in by themselves.

    Type the address of the API you want to call. See how the query parameters fill in by themselves, below.

  5. Send it

    Click Send, or press ⌘+↵.

    Click Send. And there it is: status 200, how long it took, and the size of the response.

  6. Read the response

    The body is pretty-printed. Click the time to see where it went.

    The body is nicely formatted for you. Click the time to see where it went: lookup, connection, waiting, and download.

  7. Save it to a collection

    Press ⌘+S, name it, pick or create a collection.

    Finally, save it. Press ⌘ S, give it a name, and create a collection to keep it in. Click Save, and it's ready for next time.

And that's your first request, sent and saved. Easy, right? In the next guide, we'll organise requests into collections.

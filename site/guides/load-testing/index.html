Load test an endpoint

Throw up to 500 virtual users at a request and watch latency, throughput and errors live.

Will your endpoint hold up when everyone hits it at once? Let's find out with a load test. Remember: only test servers you own, or have permission to test.

  1. Open Load test

    Request ⋯ › Load test…

    Open the request's menu, and choose Load test.

  2. Set the load

    Virtual users (up to 500), a duration or request count, ramp-up, and a rate cap.

    Set the number of virtual users, up to 500. Run for a number of seconds or requests, with an optional ramp up, and a cap on requests per second.

  3. Start and watch it live

    Throughput, p50 / p95 / p99 latency, error rate and status codes, updating live.

    Press Start. Throughput, latency percentiles, errors and status codes update live, with a chart for every second.

  4. Read the summary

    When it ends, the numbers stay. Look at p95 and the error rate first.

    When it finishes, the summary stays on screen. Look at the ninety-fifth percentile and the error rate first. They tell you the most.

Now you know how your endpoint behaves under pressure. Next: mock servers, for when the real API isn't ready yet.

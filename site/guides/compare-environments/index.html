Compare a request across environments

Send one request to staging and production at once, and see exactly what differs.

Works in sandbox, but not in production? Let's send the same request to both environments at once, and see exactly what is different.

  1. Open Compare

    Request ⋯ › Compare across environments…

    Open the request's menu, and choose Compare across environments.

  2. Pick two environments

    Choose the two to compare, say Sandbox and Production.

    Pick the two environments to compare. Here, sandbox and production.

  3. Send to both

    Send to both. Scripts run, but nothing they set is kept.

    Click Send to both. Scripts still run, but nothing they set is kept, so your environments stay clean.

  4. Read the differences

    Status, timing, headers that differ, and a value-by-value body diff.

    Now you can see status and timing side by side, the headers that differ, and a value by value diff of the body. Here, the status field and a new fees object.

Now differences between environments are easy to spot. Next, a closer look at the response panel.

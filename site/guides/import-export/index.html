Import, export, cURL and code

Bring in Postman, OpenAPI, Insomnia or HAR files, paste cURL, and turn requests into code.

Coming from another tool, or from API docs? Dispatch imports almost anything, and turns your requests into code for any language.

  1. Import a file or spec

    Import: Postman v2.0/v2.1, OpenAPI 3, Swagger 2, Insomnia and HAR. File, paste or link.

    Click Import. Choose a file, paste the text, or paste a link. Postman collections, Open API and Swagger, Insomnia and HAR files all work.

  2. Folders from tags

    OpenAPI tags become folders, with parameters, bodies and examples filled in.

    Here is the Open API spec, imported. Tags become folders, and parameters, example bodies and auth come along too.

  3. Paste a cURL command

    Paste curl … into the URL bar. It becomes a full request.

    Got a curl command from some docs? Paste it straight into the URL bar. Method, headers and body are all filled in for you.

  4. Generate code

    The </> button, or ⌥+⌘+C: cURL, Python, Go, Java, Swift and more.

    To go the other way, click the code button. Pick a language: curl, Python, Go, Java, Swift, and many more, with your variables and auth filled in.

  5. Export a collection

    Collection ⋯ › Export… writes a standard Postman file.

    And to share a collection, use Export from its menu. It writes a standard Postman file that any tool can read.

Bring work in, send it out, in whatever shape you need. Next: keeping collections in Git.

Scripts and tests

Chain tokens between requests and check every response, with Postman's pm API.

Scripts let a request do more: save a token for the next call, sign a request, or check the response is right. If you know Postman's pm API, you already know this.

  1. Open the Scripts tab

    Pre-request runs before sending. Post-response runs after.

    Open a request, and go to Scripts. Pre-request runs before it is sent. Post-response runs when the reply comes back.

  2. Save a value for later

    pm.environment.set() stores the token. Other requests use {{token}}.

    This script reads the token from the response, and saves it into the environment. Every other request can then use it, as {{token}}.

  3. Write a test

    pm.test() with pm.expect(). Real chai, lodash and crypto-js are built in.

    Tests use pm.test, with pm.expect. Let us also check the response is quick. Chai, lodash and crypto-js are all built in.

  4. Or use a snippet

    Snippets inserts ready-made recipes: token chaining, HMAC signing, conditional skips.

    Not sure what to write? Click Snippets, for ready-made recipes like token chaining and H MAC signing.

  5. Send and see results

    The Tests tab shows pass or fail. Console shows console.log output.

    Now send it. The Tests tab shows each test passing or failing, and the console shows anything you logged.

Now your requests test themselves. Next, we will run a whole collection in one go.

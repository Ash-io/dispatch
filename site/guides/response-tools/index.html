Find, filter and diff responses

Search a body, filter JSON with JSONPath, save examples, and diff against earlier responses.

Big responses can be hard to read. Let's look at the tools that help: search, JSON path filters, and diffs.

  1. Search the body

    Press ⌘+F to find text. Every match is highlighted.

    Press Command F to search the response body. Every match is highlighted.

  2. Filter with JSONPath

    Try $.data[*].email or $..name. Only the matches stay.

    For JSON, click the filter button and type a JSON path. For example, $.data[*].email, gives just the emails.

  3. Save as an example

    Response ⋯ › Save as example. Great for docs and mocks.

    Like this response? Save it as an example, from the response menu. Examples are great for docs and mock servers.

  4. Diff against before

    The Diff tab compares with an example, your history, or another tab.

    Send it again, then open the Diff tab. Compare against an example, your history, or another open tab, and see exactly which values changed.

  5. Copy, save, preview

    Copy or save the body. HTML and images get a preview.

    From the same menu, you can copy the body or save it to a file. And HTML and image responses get a proper preview.

Now no response is too big to read. Next, we'll connect to a live WebSocket.

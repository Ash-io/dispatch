Call gRPC services

Load services by reflection or .proto files, write the message as JSON, and invoke.

gRPC is fast, but it's not plain JSON over HTTP. Dispatch speaks it too. Let's call a service.

  1. New gRPC request

    Sidebar + › New gRPC request, or ⌘+K.

    Click the plus button, and choose New gRPC request.

  2. Point it at the server

    Enter host:port. Use grpcs:// for TLS.

    Enter the server address, host and port. For TLS, start it with grpcs://.

  3. Load the services

    Use server reflection, or pick your .proto files.

    Now load the services. Use server reflection if the server supports it, or choose your proto files.

  4. Write the message as JSON

    Start from the generated template. Add Metadata if needed.

    Write the request message as J SON. Dispatch gives you a template to start from, and metadata goes in its own tab.

  5. Invoke

    Replies, status, headers and trailers. Streaming replies show as they arrive.

    Click Invoke. You get the reply, the status, headers and trailers. For server streaming methods, each message shows as it arrives.

And that's gRPC, unary and streaming. Next, GraphQL with real autocomplete.

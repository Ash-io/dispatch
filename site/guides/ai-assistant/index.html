The AI assistant

Let Claude write tests from a real response, explain results, and draft requests from plain English.

Dispatch has an optional AI assistant, powered by Claude, using your own Anthropic key. It can write tests, explain responses, and draft requests for you.

  1. Add your Anthropic key

    Settings › AI assistant. The key stays on your machine, in the macOS Keychain or a private file elsewhere.

    First, add your Anthropic API key under Settings, AI assistant. It is stored on your machine (the macOS Keychain, or a private file elsewhere), never in the page.

  2. Write tests from a response

    Response ⋯ › Write tests with AI…. Nothing changes until you accept.

    Send a request, then choose Write tests with AI from the response menu. Claude reads the real response, and writes tests for it. Nothing changes until you accept.

  3. Explain a response

    Explain this response for a plain-English summary, or why a send failed.

    Not sure what a response means? Choose Explain this response, and get a plain English summary. It also explains failed sends.

  4. What gets sent

    The request as written: {{variables}} unfilled, credential headers redacted, and up to 30 KB of the response.

    What does Claude see? The request as you wrote it, with variables unfilled and credential headers removed, plus up to thirty kilobytes of the response.

Keep secrets in the Vault

API keys and passwords that never sync, never export, and never leak into scripts.

Some values should never leave your machine: live API keys, passwords, tokens. That is what the Vault is for.

  1. Open the Vault

    Environments tab, then Vault.

    Go to the Environments tab, and click Vault. Values here are stored in the macOS Keychain, or a private file on Windows and Linux.

  2. Add a secret

    Click Add secret, give it a name and a value.

    Click Add secret. Give it a name, like paystack live key, paste the value, and save.

  3. Or import a .env file

    Import .env… and paste. Many secrets at once.

    Have a .env file? Click Import .env, paste it in, and every line becomes a secret.

  4. Use it with {{vault:name}}

    Write {{vault:paystack_live_key}} in a URL, header, body or auth field.

    To use one, write {{vault:name}}. It works anywhere: URL, headers, body, or auth.

  5. What the Vault protects

    Never synced, never exported. Scripts and code snippets only see the placeholder.

    Vault values never sync to Postman, and are never exported. Scripts can't read them, and code snippets and copied curl commands only show the placeholder.

Your secrets now live in your system's secure storage, and nowhere else. Next up: authorisation.

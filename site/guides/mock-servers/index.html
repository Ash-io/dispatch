Examples and mock servers

Save responses as examples, then serve them from a local mock server.

Building a front end before the back end is ready? Save example responses, and Dispatch will serve them from a mock server on your computer.

  1. Saved examples

    Examples sit under their request. Save one from any response with Save as example.

    Examples are saved responses. They sit under their request in the sidebar. You can save any response as an example from its menu.

  2. Edit an example

    Change its status, headers and body. Add, rename or duplicate examples.

    Open one to edit it. Set the status code, headers and body to whatever the real API will return.

  3. Start the mock server

    Collection ⋯ › Mock server… › Start.

    Now open the collection menu, choose Mock server, and press Start. Every example becomes a route.

  4. Call it

    Calls to localhost:4010 appear in the log. Pick an example with x-mock-response-code.

    Point your app at localhost. Each request shows up in the log. To get the error example, send the header x mock response code.

  5. Point {{baseUrl}} at it

    One click makes an environment where {{baseUrl}} is the mock.

    And with one click, Dispatch makes an environment where {{baseUrl}} points at the mock. Switch to it, and your requests hit the mock instead.

Your front end can now work against the mock, until the real API is ready. Next, we will compare two environments side by side.

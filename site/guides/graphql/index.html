GraphQL with autocomplete

Load the schema, get field suggestions and checks as you type, and explore the API.

With GraphQL, knowing the schema is half the work. Dispatch loads it for you, then helps as you type.

  1. Choose a GraphQL body

    In Body, pick GraphQL.

    Point a request at your GraphQL endpoint. Then in the Body tab, choose GraphQL.

  2. Load the schema

    Load schema introspects the endpoint, with your headers and auth.

    Click Load schema. Dispatch asks the server for its schema, using the same headers and auth as your request.

  3. Type with suggestions

    Fields complete as you type. ⌃+Space asks for suggestions anywhere.

    Now start typing. Fields are suggested as you go, and Control Space brings up suggestions anywhere.

  4. Mistakes are flagged

    Unknown fields, missing arguments and bad selections are underlined.

    Mistakes are caught before you send. Unknown fields, missing arguments and bad selections are underlined, with a note explaining why.

  5. Send and explore

    Send it. The schema explorer lists every type and field.

    Send it, and the answer comes back as usual. The schema explorer lets you browse every type and field.

Schema loaded, query checked, answer back. Next, let's meet the AI assistant.

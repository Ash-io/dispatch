Set up a Dispatch server for your team

Run dispatch-server on your own machine, Docker, or Cloudflare, and claim it as admin.

Want your whole team in Dispatch, with its own accounts and access control? Run a Dispatch server. It's one small program, and it's entirely optional.

  1. Run the server

    Download the binary from the release, or use Docker. It listens on port 8383.

    Download dispatch server from the releases page and run it, or use Docker, with a volume for its database. By default it listens on port 8383.

  2. Or deploy to Cloudflare

    Deploy to Cloudflare button in the README, or npm run deploy:server. Set a SECRET_KEY.

    Prefer the cloud? The Deploy to Cloudflare button sets it up on your own Cloudflare account, with its database. Set a secret key: it encrypts the Postman keys you add later.

  3. Claim it straight away

    Open /admin/, choose New server? Create the first account. The first account becomes admin.

    Now, straight away, open /admin/, and create the first account. The first person to register becomes the admin, so do this before you share the address.

  4. Close registration

    Settings: turn off open registration. You add people yourself from now on.

    Registration is open by default. Once your team is in, or if you'd rather add people yourself, turn it off in Settings.

Your server is up, and you're its admin. Next, we'll connect Postman accounts and invite your team.

Organise requests with collections and folders

Group requests into collections and folders, share settings across them, and document them.

Once you have a few requests, you'll want to keep them tidy. Let's look at collections, folders, and the settings they share.

  1. Create a collection

    Click + in the sidebar, then New collection.

    Click the plus button in the sidebar, then New collection. Give it a name, and click Create.

  2. Add folders and requests

    Open a collection's ⋯ menu: Add folder, Add request.

    Every collection has a menu. Here you can add folders to group related requests, and add new requests straight into them.

  3. Drag to reorder

    Drag requests and folders to move them, in or between collections.

    To move things around, just drag them. Requests and folders can move within a collection, or into another one.

  4. Shared auth and variables

    Settings, auth & variables: set auth once, every request inherits it.

    Open the collection's settings. Authorisation set here is inherited by every request inside, and collection variables, like {{baseUrl}}, work everywhere in it.

  5. Write docs in Markdown

    The Overview tab takes Markdown, with a live preview.

    The Overview tab is for documentation. Write in Markdown, and switch to Preview to see it formatted. It syncs with Postman too.

  6. See how requests connect

    Request chain shows which request sets a variable, and which ones use it.

    Finally, Request chain. It shows your requests in run order, with arrows from the request that sets a variable to the ones that use it.

Now your requests have a proper home. Next, we will make them work across environments with variables.

Run a whole collection

Run every request in order, repeat it with data files, and see a pass or fail matrix.

Clicking Send on every request gets old quickly. The collection runner sends them all, in order, and checks every test.

  1. Open the runner

    Collection or folder ⋯ › Run collection.

    Open the collection menu, and click Run collection. You can run a single folder the same way.

  2. Set iterations and environment

    Iterations, a delay between them, and which environment to use.

    Choose how many times to run it, an optional delay between iterations, and which environment to use.

  3. Feed it a data file

    Data file…: CSV or JSON. Each row is one iteration, as {{data}} variables.

    Want different inputs each time? Add a data file, CSV or JSON. Each row becomes one iteration, and its columns become variables.

  4. Run it

    Press Run. Stop halts it mid-run.

    Press Run, and watch each request go through. You can stop it at any time.

  5. Read the matrix

    Every request, every iteration, every test. Click a cell for details.

    The results show every request across every iteration, with each test's result. Your past runs are kept in history too.

One click, every request tested. Next, we will put an endpoint under load.

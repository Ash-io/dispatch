Live WebSocket connections

Open a socket, watch frames stream in, and send messages back.

Some APIs don't just answer once, they keep talking. Let's open a WebSocket and chat with it, live.

  1. Use a ws:// or wss:// URL

    Open a new request and type a wss:// address. Send now opens a live connection.

    Open a new request, and type an address starting with ws:// or wss://. Now Send opens a live connection, instead of a one-off request.

  2. Connect and watch frames

    Click Send to connect. Incoming frames stream in with their size and time.

    Click Send to connect. Messages from the server stream in as they arrive, with their size and time.

  3. Send a message

    Write a message and press Send frame. It shows as an outgoing frame.

    To talk back, write a message, and press Send frame. It appears in the log as an outgoing frame, and the reply follows.

  4. Close cleanly

    Close ends the session with a proper close frame.

    When you are done, click Close. Dispatch ends the session cleanly, with a proper close frame.

That's WebSockets: connect, watch, reply, close. Next up, gRPC.

Keep collections in Git

Save a collection as readable files, commit it with your code, and review changes in pull requests.

Want your API requests reviewed in pull requests, right next to your code? Save the collection to a folder, and keep it in Git.

  1. Save to a folder

    Collection ⋯ › Save to a folder (Git)…, then pick a folder in your repo.

    Open the collection menu, and choose Save to a folder. Pick a folder inside your repository.

  2. Readable files

    collection.json, a folder.json per folder, one .request.json per request.

    Dispatch writes plain, readable files. One for the collection, one per folder, and one per request, with its examples. File names stay stable, even when you rename things.

  3. Commit and push

    Every save updates the files. Commit them like any other code.

    Every time you save in Dispatch, the files update. Commit and push them like any other code, and review changes in pull requests.

  4. Open a teammate's collection

    + › Open collection from folder…. Pulled changes load when Dispatch regains focus.

    Teammates use Open collection from folder, on a cloned repo. After a git pull, changes load as soon as Dispatch comes back into focus.

Your collection now lives in Git, versioned with your code. Next, we'll run it from the command line, and in CI.
